# GMT Scripts — Marine Geodetic and Geophysical Mapping of the Seychelles and the Somali Sea

GMT scripts used in the peer-reviewed article by Polina Lemenkova and Olivier Debeir.

**Paper:** Satellite Altimetry and Gravimetry Data for Mapping Marine Geodetic and Geophysical Setting of the Seychelles and the Somali Sea, Indian Ocean
**Published in:** *Journal of Applied Engineering Sciences* **2022**, *12*(2), 191–202
**DOI:** https://doi.org/10.2478/jaes-2022-0026

## Contents
Generic Mapping Tools (GMT) shell scripts for mapping free-air gravity anomalies, geoid undulation, sediment thickness and bathymetry over the Seychelles and the Somali Sea, using satellite altimetry and gravimetry grids.

The LaTeX **manuscript** source for this article is in a companion repository: https://github.com/paulinelemenkova/gmt-altimetry-gravimetry-seychelles-somali-sea
